# muon S2 波形过阈统计（7/7 全触发子集）

## 数据与判据

| 项 | 设定 |
|---|---|
| 事例集合 | `n_an_pulse == 7` 且 `n_dy_pulse == 7` 的 muon 事例，**n = 5,808** |
| 波形 | `anode_sum`（阳极求和波形，已扣除基线） |
| S2 段范围 | `[muon_s1_end_sample, muon_s2_end_sample)` |
| 变换 | 每个采样点 **×30** |
| 阈值 | **\|值\| > 1695**（等价于原始 **56.5 ADC**） |

数据来源：
- 事例筛选：`peak_level_v2/muon_an_dy_channel_ratio.csv`
- 波形：`peak_level_v2/sum_waveforms/run_XXXXX.npz`（`muon_analysis.sum_store.load_sum_npz`）
- 峰值参数：`peak_level_v2/co60_590_peak_level_v2.csv`

复现脚本：`scripts/muon_s2_over_threshold.py`

## 基线验证（确认 91% 非偏置伪影）

| 位置 | 中位 ADC |
|---|---|
| 脉冲前基线（t < 0，前 50 点） | **0.0** |
| S2 段第 3/4 处 | −239（仍远高于阈值当量 56.5） |
| 记录最末 50 点 | **6.0**（q25–q75：4–9.5） |
| 最末 50 点低于阈值的事例 | **99.8%** |

- 脉冲前基线中位为 **0.0 ADC** → 基线已正确扣除
- 记录最末 50 点中位仅 **6 ADC** → 波形在记录末段确已回到基线
- S2 段第 3/4 处仍为 **−239 ADC** → S2 段覆盖的时间内信号尚未回基线

## 结论

S2 段覆盖的时间范围内，慢衰减分量**在约 91% 的采样点上都高于 56.5 ADC**，直到记录末段（约 25–27 µs）才回到基线。这是**真实的慢分量**，不是基线偏移造成的假象。

即：7/7 全触发 muon 事例的 S2 波形，其宽度基本由记录长度决定，**绝大部分采样点都处于过阈状态**。
