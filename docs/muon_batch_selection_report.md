## 1. 筛选判据

对每个 run：`read → match → cluster → 保留 n_channels≥7 → 寻峰(start/end) → peak 特征 → 筛选`

```
n_channels ≥ 7            （7 PMT 全命中，多通道符合）
peak_height > 10000 ADC   （大幅值）
anode_area_pe > 5000 PE   （高电荷）
peak_width_ns > 5000 ns   （长事件窗口 >5µs）
```

> 依据历史分析：7 通道全命中（0.12% 保留率）+ 延展型长窗口 + 高电荷最切合 muon 的
> TPC 漂移信号特征（详见开发进展 §4 与 batch 前逐事例分析）。

## 6. 结论与后续

- 四判据联合（7ch 全命中 + 大幅值 + 高电荷 + 长窗口 >5µs）在 50 runs 中筛出 **38 个候选**
  （0.7 run⁻¹），均为强 muon 信号特征（延展型、全 PMT、高电荷）。
- 候选 peak 级数据已落盘，可直接用于径迹重建、COG 位置分析与事例率估计。
- 后续：对 38 个候选做波形验证、径迹重建、位置分布分析；阈值如需微调可改
  `scripts/batch_muon_select.py` 顶部常量后重跑（每 run 输出可续跑/覆盖）。
