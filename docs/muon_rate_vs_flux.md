## 4. 几何期望率

海平面 μ 子全角度通量（向下 2π，p_μ > 1 GeV）：

```
Φ ≈ 1 cm⁻² min⁻¹ = 167 m⁻² s⁻¹
R_geom = Φ × A_TPC = 167 × 8.5×10⁻³ = 1.420 s⁻¹
       = 85.2 min⁻¹ = 5,110 h⁻¹
```

## 5. 对比

| 选择 | R_meas [s⁻¹] | ε = R_meas/R_geom | 隐含通量 [m⁻²s⁻¹] |
|---|---|---|---|
| 全部 | 0.763 | **53.7%** | 89.8（= Φ 的 54%）|
| `n_ch == 7` | 0.151 | **10.6%** | 17.8（= Φ 的 11%）|
| 几何期望 | 1.420 | 100% | 167 |

### 解读

- **`n_ch == 7` 选择（ε ≈ 11%）是物理上合理的 μ 子选择**：μ 子贯穿 TPC 灵敏体积，
  应在全部 7 个 PMT 上产生光信号。11% 的效率包含：
  - **几何接收度**：只有穿过灵敏体积（≈ 84 cm² 截面 × 50 mm 漂移长度）的 μ 子才被探测；
    倾斜径迹可能只照亮部分 PMT，不满足 7 通道全符合
  - **触发效率**：self-trigger 阈值（anode 40 ADC）+ 符合逻辑
  - **宽脉冲判据**：`width_ns>2000 ∧ width_90area>1000` 只保留长径迹/多簇事例
  - **DAQ 死时间**：self-trigger 模式下的活时间未单独扣除
- **"全部"选择（ε ≈ 54%）包含了大量单通道事例**（30,723 / 49,435 = 62%），
  这些很可能是噪声/余脉冲/局部闪烁，不是贯穿 μ 子——故效率"虚高"，不能直接对比。

### 与早期 No-Field 分析的一致性

`docs/muon_algorithm_architecture.md` 的早期分析（5 cm 直径探测器、更严的 cut
`n_ch≥7 ∧ height>15000 ∧ anode_sum_area>10000 PE ∧ width_ns>5000`）：
```
R_meas = 48 / 18,000 s = 2.67×10⁻³ s⁻¹
A = π(2.5cm)² = 19.6 cm²  →  R_geom = 167 × 1.96×10⁻³ = 0.327 s⁻¹
ε = 0.81%
```
本次用**真实 TPC 截面（85 cm²，比 5cm 探测器大 4.3 倍）**且 cut 更宽松
（`width_ns>2000` vs `>5000`，无 height/area 阈值），ε 从 0.81% 升至 10.6%——
两者量级递进合理（更宽的 cut + 正确的探测器面积）。

## 6. 待确认 / 可改进

1. **活时间**：self-trigger 模式下 DAQ 死时间未扣除；若需精确率需用触发计数器估算 live time
2. **是否应限定 `n_ch == 7`**：当前 TPC 分析建议以此作为 μ 子选择
3. **是否加高度/面积阈值**：`height`、`anode_sum_area` 可进一步压制噪声
4. **TPC 截面取值**：84.1 cm²（PMT 覆盖）vs 89.9 cm²（外接圆）——差异 7%，对 ε 影响同量级
