## 3. TPC 截面

**取自上而下的有效截面（5 cm 直径圆）**

```
A = πr² = π(2.5 cm)² = 19.63 cm² = 1.963×10⁻³ m²
```

（说明：PMT 阵列本身为 7 个六边形 PMT、边长 21.5 mm、环半径 32 mm，合计 84.1 cm²；
但自上而下贯穿的有效灵敏截面按 5 cm 直径圆取，即 **19.63 cm²**。）

**漂移区（`dec_info`，供参考）**
| 项 | 值 |
|---|---|
| Anode_Gate_gap | 10.0 mm |
| Gate_Cathode_gap | **40.0 mm**（漂移长度）|
| Anode / Gate / Cathode | 3.2 kV / −1.0 kV / −1.32 kV |

## 4. 几何期望率

海平面 μ 子全角度通量（向下 2π，p_μ > 1 GeV）：

```
Φ ≈ 1 cm⁻² min⁻¹ = 167 m⁻² s⁻¹
R_geom = Φ × A = 167 × 1.963×10⁻³ = 0.328 s⁻¹
       = 19.67 min⁻¹ = 1,180 h⁻¹
```

## 5. 对比

### 5a. 无 height cut：`width_ns > 2000 ∧ width_90area > 1000`

| 选择 | N | R_meas [s⁻¹] | **ε = R_meas/R_geom** | 隐含通量 [m⁻²s⁻¹] |
|---|---|---|---|---|
| 全部 | 49,435 | 0.763 | **232.7%** | 388.5 |
| `n_ch == 1` | 30,723 | 0.474 | 144.6% | 241.5 |
| `2 ≤ n_ch ≤ 6` | 8,931 | 0.138 | 42.0% | 70.2 |
| **`n_ch == 7`** | **9,781** | **0.151** | **46.0%** | **76.9** |
| 几何期望 | — | 0.328 | 100% | 167 |

### 5b. 加 `height > 1.5×10⁴ ADC`

| 选择 | N | R_meas [s⁻¹] | **ε = R_meas/R_geom** | 隐含通量 [m⁻²s⁻¹] |
|---|---|---|---|---|
| 全部 | **15,636** | **0.241** | **73.6%** | **122.9** |
| `n_ch == 1` | **112** | 0.0017 | **0.5%** | 0.9 |
| `2 ≤ n_ch ≤ 6` | 5,743 | 0.089 | 27.0% | 45.1 |
| **`n_ch == 7`** | **9,781**（不变）| **0.151** | **46.0%** | **76.9** |
| 几何期望 | — | 0.328 | 100% | 167 |

其他量（有 height cut）：`height` 中位 52,054 ADC、`anode_sum_area` 中位 25,616 PE、
`signal_type` 全部为 **S2**。

### 解读

- **`height > 1.5×10⁴ ADC` 几乎完全清除单通道噪声**：`n_ch == 1` 从 30,723 → **112**
  （ε 从 144.6% → **0.5%**）。这证实单通道事例确实以噪声/余脉冲为主。
- **`n_ch == 7` 完全不受 height cut 影响**（9,781 不变）：7 通道全符合的事例本身
  `height` 就很高 → **ε = 46.0%**，是物理上最可信的 μ 子选择。
- **加 height cut 后"全部"ε 从 233% 降至 73.6%**（低于几何期望 100%），
  说明该 cut 有效压制了非 μ 子本底；剩余 73.6% 包含 `n_ch==7`（46%）+
  `2-6 ch`（27%，可能是只照亮部分 PMT 的倾斜/边缘径迹）。
- **逐 run 计数**：391（run 590）～ 1,169（run 602），多数在 560-1,160；
  run 590 明显偏低（可能是该 run 条件/触发阈值不同）。

### 与早期 No-Field 分析的一致性

`docs/muon_algorithm_architecture.md` 的早期分析使用**相同的 5 cm 直径截面**、
更严的 cut（`n_ch≥7 ∧ height>15000 ∧ anode_sum_area>10000 PE ∧ width_ns>5000`）：

```
R_meas = 48 / 18,000 s = 2.67×10⁻³ s⁻¹
R_geom = 167 × 1.963×10⁻³ = 0.328 s⁻¹
ε = 0.81%
```

本次 `n_ch==7` 组（height>15k 下 9,781 个）cut 更宽松（`width_ns>2000` vs `>5000`，
无 `anode_sum_area` 阈值），ε 从 0.81% → 46.0%——放宽宽度阈值后效率大幅提升，
量级递进合理。

## 6. 待确认 / 可改进

1. **活时间**：self-trigger 模式下 DAQ 死时间未扣除；若需精确率需用触发计数器估算 live time
2. **是否应限定 `n_ch == 7`**：当前分析建议以此作为 μ 子选择（ε ≈ 46%，物理合理）
3. **是否加 `anode_sum_area` 阈值**：早期分析用 `>10000 PE`，可进一步收紧
4. **截面取值**：按自上而下 5 cm 直径圆取 19.63 cm²（本文）；若按 PMT 阵列覆盖则为 84.1 cm²
