> 数据：`/mnt/data/tmp/muon_analysis/co60_590/peak_level_v2/co60_590_peak_level_v2_with_signal.csv`
> （18 run，新 clustering：pulse-start 参考 + 320ns 窗口）

**Cut**：`width_ns > 2000 ns` **AND** `width_90area > 1000 ns`

| 选择 | 事例数 N |
|---|---|

| 其中 `n_ch == 7` | **9,781** |
| 其中 `n_ch == 1` | 30,723 |
| 其中 `2 ≤ n_ch ≤ 6` | 8,931 |

## 2. 实测率

观测时间 `T = 18 run × 3600 s = 64,800 s = 18.0 h`

| 选择 | R_meas |
|---|---|
| 全部 | **0.763 s⁻¹ = 45.8 min⁻¹ = 2,746 h⁻¹** |
| `n_ch == 7` | **0.151 s⁻¹ = 9.06 min⁻¹ = 543 h⁻¹** |

## 3. TPC 截面

**取自上而下的有效截面（5 cm 直径圆）**

```
A = πr² = π(2.5 cm)² = 19.63 cm² = 1.963×10⁻³ m²
```

（说明：PMT 阵列本身为 7 个六边形 PMT、边长 21.5 mm、环半径 32 mm，合计 84.1 cm²；
但自上而下贯穿的有效灵敏截面按 5 cm 直径圆取，即 **19.63 cm²**。）

**漂移区（`dec_info`，供参考）**
| 项 | 值 |
|---|---|
| Anode_Gate_gap | 10.0 mm |
| Gate_Cathode_gap | **40.0 mm**（漂移长度）|
| Anode / Gate / Cathode | 3.2 kV / −1.0 kV / −1.32 kV |
| 工质 | LXe（pressure 1.34 bar, T 171.7 K）|

## 4. 几何期望率

海平面 μ 子全角度通量（向下 2π，p_μ > 1 GeV）：

```
Φ ≈ 1 cm⁻² min⁻¹ = 167 m⁻² s⁻¹
R_geom = Φ × A = 167 × 1.963×10⁻³ = 0.328 s⁻¹
       = 19.67 min⁻¹ = 1,180 h⁻¹
```

## 5. 对比

| 选择 | N | R_meas [s⁻¹] | **ε = R_meas/R_geom** | 隐含通量 [m⁻²s⁻¹] |
|---|---|---|---|---|
| 全部 | 49,435 | 0.763 | **232.7%** | 388.5 |
| `n_ch == 1` | 30,723 | 0.474 | 144.6% | 241.5 |
| `2 ≤ n_ch ≤ 6` | 8,931 | 0.138 | 42.0% | 70.2 |
| **`n_ch == 7`** | **9,781** | **0.151** | **46.0%** | **76.9** |
| 几何期望 | — | 0.328 | 100% | 167 |

### 解读

- **`n_ch == 7`（ε ≈ 46%）是物理上合理的 μ 子选择**：μ 子贯穿 TPC 灵敏体积，
  应在全部 7 个 PMT 上产生光信号。46% 的效率损失来自几何接收度（倾斜径迹不满
  7 通道全符合）、self-trigger 触发效率、宽脉冲判据，以及未扣除的 DAQ 死时间。
- **"全部"（ε ≈ 233%）超过几何期望 2.3 倍 → 不可能全是 μ 子**：其中 62%
  （30,723）是**单通道事例**（`n_ch == 1`，ε 已达 145%），很可能是噪声 / 余脉冲 /
  局部闪烁，而非贯穿 μ 子。必须用 `n_ch == 7` 之类的符合判据才能与 μ 子通量对比。
- **`2 ≤ n_ch ≤ 6`（ε ≈ 42%）** 与 7 通道组接近，但其成分复杂（部分 μ 子 + 部分噪声）。

### 与早期 No-Field 分析的一致性

`docs/muon_algorithm_architecture.md` 的早期分析使用**相同的 5 cm 直径截面**、
更严的 cut（`n_ch≥7 ∧ height>15000 ∧ anode_sum_area>10000 PE ∧ width_ns>5000`）：

```
R_meas = 48 / 18,000 s = 2.67×10⁻³ s⁻¹
R_geom = 167 × 1.963×10⁻³ = 0.328 s⁻¹
ε = 0.81%
```

本次 cut 更宽松（`width_ns>2000` vs `>5000`，无 height/area 阈值），
`n_ch == 7` 组从 48 → 9,781 个事例，ε 从 0.81% → 46.0%——
放宽宽度阈值后效率大幅提升，量级递进合理。

## 6. 待确认 / 可改进

1. **活时间**：self-trigger 模式下 DAQ 死时间未扣除；若需精确率需用触发计数器估算 live time
2. **是否应限定 `n_ch == 7`**：当前分析建议以此作为 μ 子选择（ε ≈ 46%，物理合理）
3. **是否加高度/面积阈值**：`height`、`anode_sum_area` 可进一步压制噪声
4. **截面取值**：按自上而下 5 cm 直径圆取 19.63 cm²（本文）；若按 PMT 阵列覆盖则为 84.1 cm²
