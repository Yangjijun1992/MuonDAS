# 宽脉冲事例率 vs 本地 μ 子通量（Co60 590+ 18 run）

> 数据：`/mnt/data/tmp/muon_analysis/co60_590/peak_level_v2/co60_590_peak_level_v2_with_signal.csv`
> （18 run，新 clustering：pulse-start 参考 + 320ns 窗口）

## 0. 最终分类与 μ 子选择（结论）

### 分类算法（`src/muon_analysis/signal_id.py`，判据互斥）

```
S1    : width_20_50area < 100 ns  AND  width_90area < 1000 ns
muon  : n_ch >= 2  AND  height > 1.5e4 ADC  AND  width_ns > 2000 ns
        AND  width_90area > 1000 ns  AND  anode_sum_area > 300 PE
S2    : width_90area > 1000 ns  AND  width_ns > 2000 ns
        AND  anode_sum_area > 300 PE  AND  height < 1.5e4 ADC
other : 其余
```

### 分类结果与率（T = 64,800 s = 18.0 h，A = 19.63 cm²，R_geom = 0.328 s⁻¹）

| signal_type | N | R [s⁻¹] | R [min⁻¹] | R [h⁻¹] | ε = R/R_geom | 通量 [m⁻²s⁻¹] |
|---|---|---|---|---|---|---|
| S1 | 685,024 | 10.5714 | 634.28 | 38,057 | 3,223.9% | 5,383.9 |
| **muon（μ 子选择）** | **15,524** | **0.2396** | **14.37** | **862** | **73.1%** | **122.0** |
| S2 | 33,608 | 0.5186 | 31.12 | 1,867 | 158.2% | 264.1 |
| other | 2,252 | 0.0348 | 2.09 | 125 | 10.6% | 17.7 |
| **合计** | **736,408** | 11.364 | 681.9 | 40,912 | 3,465.7% | 5,787.8 |
| **几何期望** | — | **0.3279** | **19.67** | **1,180** | 100% | 167 |

**结论**：`muon` 组 **R = 0.240 s⁻¹ = 14.37 min⁻¹ = 862 h⁻¹**，
通量 **122.0 m⁻²s⁻¹**，为海平面几何期望 **167 m⁻²s⁻¹ 的 73.1%** ——
与 μ 子通量量级一致（剩余 ~27% 来自几何接收度、self-trigger 触发效率、
宽脉冲/高度判据、未扣除的 DAQ 死时间）。

`S1`（ε=3,224%）与 `S2`（ε=158%）**远超几何期望** → 主体为低能 γ / 噪声，
**不能与 μ 子通量对比**。

详细参数范围见 `docs/other_muon_candidates_params.md`。

## 5. 对比

### 5a. 无 height cut：`width_ns > 2000 ∧ width_90area > 1000`

### 5b. 加 `height > 1.5×10⁴ ADC`

### 5c. 再加 `n_ch >= 2`（4-cut）

| 选择 | N | R_meas [s⁻¹] | **ε = R_meas/R_geom** | 隐含通量 [m⁻²s⁻¹] |
|---|---|---|---|---|
| 3-cut（上表"全部"）| 15,636 | 0.241 | 73.6% | 122.9 |
| **4-cut（+`n_ch >= 2`）** | **15,524** | **0.240** | **73.1%** | **122.0** |
| 几何期望 | — | 0.328 | 100% | 167 |

`n_ch` 分布（4-cut）：`{2: 1218, 3: 1832, 4: 1274, 5: 664, 6: 755, 7: 9781}`

> `n_ch >= 2` 只剔除 112 个单通道事例（已被 height cut 压到 0.5%），
> 故 4-cut 与 3-cut 几乎等价（ε 73.6% → 73.1%）。

### 5d. 低高度侧：`width_ns > 2000 ∧ width_90area > 1000 ∧ height < 1.5×10⁴ ADC`

| 选择 | N | R_meas [s⁻¹] | **ε = R_meas/R_geom** | 隐含通量 [m⁻²s⁻¹] |
|---|---|---|---|---|
| `height > 1.5e4`（3-cut）| 15,636 | 0.241 | 73.6% | 122.9 |
| **`height < 1.5e4`** | **33,799** | **0.522** | **159.1%** | **265.6** |
| 几何期望 | — | 0.328 | 100% | 167 |

`n_ch` 分布（`height < 1.5e4`）：`{1: 30611, 2: 2505, 3: 629, 4: 54}`，
**`n_ch == 7` 为 0 个**

> **结论：`height < 1.5e4` 组不是 μ 子**。
> - 其率 **ε = 159.1%** 已**超过几何 μ 子期望 1.6 倍**——若全是 μ 子则不可能；
> - 90.6%（30,611/33,799）是**单通道**事例，且 **7 通道全符合事例为 0**——
>   而 μ 子贯穿 TPC 应在全部 7 个 PMT 上产生信号；
> - 故该组以噪声 / 余脉冲 / 局部闪烁为主，`height > 1.5×10⁴ ADC` 是必要的 μ 子判据。

### 解读

- **`height > 1.5×10⁴ ADC` 几乎完全清除单通道噪声**：`n_ch == 1` 从 30,723 → **112**
  （ε 从 144.6% → **0.5%**）。这证实单通道事例确实以噪声/余脉冲为主。
- **`n_ch == 7` 完全不受 height cut 影响**（9,781 不变）：7 通道全符合的事例本身
  `height` 就很高 → **ε = 46.0%**，是物理上最可信的 μ 子选择。
- **加 height cut 后"全部"ε 从 233% 降至 73.6%**（低于几何期望 100%），
  说明该 cut 有效压制了非 μ 子本底；剩余 73.6% 包含 `n_ch==7`（46%）+
  `2-6 ch`（27%，可能是只照亮部分 PMT 的倾斜/边缘径迹）。
- **逐 run 计数**：391（run 590）～ 1,169（run 602），多数在 560-1,160；
  run 590 明显偏低（可能是该 run 条件/触发阈值不同）。

### 与早期 No-Field 分析的一致性

`docs/muon_algorithm_architecture.md` 的早期分析使用**相同的 5 cm 直径截面**、
更严的 cut（`n_ch≥7 ∧ height>15000 ∧ anode_sum_area>10000 PE ∧ width_ns>5000`）：

```
R_meas = 48 / 18,000 s = 2.67×10⁻³ s⁻¹
R_geom = 167 × 1.963×10⁻³ = 0.328 s⁻¹
ε = 0.81%
```

本次 `n_ch==7` 组（height>15k 下 9,781 个）cut 更宽松（`width_ns>2000` vs `>5000`，
无 `anode_sum_area` 阈值），ε 从 0.81% → 46.0%——放宽宽度阈值后效率大幅提升，
量级递进合理。

## 6. 待确认 / 可改进

1. **活时间**：self-trigger 模式下 DAQ 死时间未扣除；若需精确率需用触发计数器估算 live time
2. **是否应限定 `n_ch == 7`**：当前分析建议以此作为 μ 子选择（ε ≈ 46%，物理合理）
3. **是否加 `anode_sum_area` 阈值**：早期分析用 `>10000 PE`，可进一步收紧
4. **截面取值**：按自上而下 5 cm 直径圆取 19.63 cm²（本文）；若按 PMT 阵列覆盖则为 84.1 cm²
