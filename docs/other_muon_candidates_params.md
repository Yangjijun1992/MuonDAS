## 4. 关键判据（μ 子候选，建议）

```
n_ch == 7
height > 1.5×10⁴ ADC          （中位 63,195；q25 53,740）
width_ns > 2000 ns            （中位 26,888）
width_90area > 1000 ns        （中位 19,605）
anode_sum_area > 300 PE       （中位 30,540）
```

**证实 `other` 中的高高度宽脉冲组就是 μ 子候选**。

## 5. 重要观察：`width_ns` 被记录长度截断

`n_ch==7` 子集的 `width_ns` 中位 **26,888 ns**，q25–q75 仅 **26,236–27,580 ns**（极窄），
`wave_len_samples` 中位 6,772（≈ 27.1 µs）。

→ 这些 μ 子事例的 sum 波形**在记录结束前未回到基线**，故
`width_ns = (end_final − a_st)×4ns ≈ 记录长度`——**宽度被记录长度饱和**，
不反映真实脉冲宽度。这与 `docs/end_first_muon_s1_issue.md` 的拖尾问题同源。

**含义**：`width_ns` 对 μ 子事例不是好的判别量；`height` / `anode_sum_area` /
`n_samples_gt1000adc` 更有区分力。
